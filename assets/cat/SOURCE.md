# 跟随小猫来源

更新日期：2026-10-27。

基于“个人网站 2 开发问题QA”的 cat-interaction-preview-20261026/cat.js 整合，原实现改编自 [adryd325/oneko.js](https://github.com/adryd325/oneko.js)。保留源预览的 oneko 精灵图及完整 MIT 许可（LICENSE-oneko.txt）。

整站版本添加公共延迟加载、实例防重、页脚开关、偏好同步、触屏与减少动态效果支持、后台及弹窗暂停。小猫保持点击穿透；滚轮和链接悬停不会使其隐藏，小链接及实际控件通过位置避让，大项目卡片不触发整片隐藏。

本轮将社交按钮的实际边界合并为包含图标间隙的避让区域，并在组内切换时保持同一侧目标。控件避让只改变目标，取消直接修改坐标的瞬移；移动时通过 requestAnimationFrame 连续更新，按时间差限制最大速度为 155px/s，并平滑加减速及转向。精灵动作和目标检测仍约 10Hz，停留时以 100ms 定时等待；后台恢复重置计时与速度，不补算离开期间的位移。

通过 sessionStorage 保存坐标、鼠标目标与待机状态，并在同源站内跳页或刷新后恢复；已有会话状态时立即加载，首次访问仍在空闲时加载。多文档导航会替换页面，因此不承诺跨页绝对没有绘制间隙。使用本地同源 HTTP 预览检查连续性，file:// 页面的存储可能被浏览器分别隔离。

全部脚本和精灵图来自本站目录，不使用外部 CDN；运行资源合计 17,915 字节，约 18 KB。开关、设备与后台约束在本轮修复后保持不变。
