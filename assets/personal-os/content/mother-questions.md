# 母题

## 一、从一个可以反复追问的问题开始

母题是会在不同生活情境中反复出现的根本问题。例如：什么值得投入、证据不足时怎样行动、何时继续或退出。围绕同一个问题，持续整理来源、模型、案例与反例。

本项目有三个入口：**核心母题**保存跨领域问题；**认知工具**整理原则、模型、认知卡与来源笔记；**实验反馈**组织案例、复盘和后续修订。它们构成独立项目，与人生元系统、判断与退出、人生清单并列。

## 二、问题、工具与验证如何相连

```text
现实输入：文章 / 书籍 / 经历 / 对话 / 观察
                      ↓
             素材收集（Inbox）
                      ↓
        事实、解释、价值判断分别记录
                      ↓
              归属领域 Domain
                      ↓
           提取底层母题 Question
                      ↓
         连接已有原则 / 模型 / 案例
                      ↓
           形成假设、问题或决策
                      ↓
            行动 / 低成本试验
                      ↓
           检查：继续 / 调整 / 退出
                      ↓
           复盘与证据、版本更新
                      ↺
```

### 系统中的七类知识对象

| 对象 | 负责回答 | 示例 |
|---|---|---|
| 领域 Domain | 这件事发生在人生哪个方面？ | 爱情、职业、健康 |
| 母题 Mother Question | 这属于哪一类反复出现的根本问题？ | 何时坚持、何时退出？ |
| 原则 Principle | 我暂时认可的判断规则是什么？ | 保持现状也应进入选项集合 |
| 模型 Model | 我用什么方法分析？ | 机会成本、预期价值、退出合约 |
| 来源 Source | 观点从哪里来、原文说了什么？ | 书籍、文章、自己的观察 |
| 案例 Case | 规则在现实中表现怎样？ | 健身房选择、项目推进 |
| 复盘 Review | 应保留、修改还是废弃什么？ | 预期与结果的差异 |

**关系规则**：一篇来源可关联多个母题；同一母题可跨多个领域；原则和模型可以应用于多个案例。不要机械地把所有知识锁进唯一文件夹。

## 三、首批跨领域母题

母题是可持续追问的问题，不是看起来很深刻的口号。

| ID | 母题 | 常见关联领域 |
|---|---|---|
| MQ-001 | 什么值得投入我的时间、金钱和注意力？ | 时间、金钱、职业、爱情 |
| MQ-002 | 信息不完整时，何时分析、何时行动？ | 学习、职业、社会 |
| MQ-003 | 失败损失多大？决定是否可逆？ | 金钱、职业、健康 |
| MQ-004 | 何时坚持、调整或退出？ | 全领域 |
| MQ-005 | 哪些是事实，哪些只是我的解释？ | 社会、友情、爱情 |
| MQ-006 | 短期舒服与长期利益是否冲突？ | 时间、健康、学习 |
| MQ-007 | 是真正成长，还是只有成长的感觉？ | 学习、职业、健康 |
| MQ-008 | 保持现状的隐性机会成本是什么？ | 全领域 |
| MQ-009 | 哪些约束是不能用其他优点抵消的？ | 健康、职业、关系 |
| MQ-010 | 能否用一个小实验获得关键新信息？ | 全领域 |

初始母题不追求完整。只有当新问题长期无法合理归类时才新增；重复问题优先建立交叉链接。

## 四、认知工具与知识吸收

### 1. 先拆解，不直接吸收

新内容进入 Inbox 后，提取：**核心命题、作者证据、推理机制、适用条件、可能反例、来源链接、对我行为的影响**。明确区分：

- **事实**：可核对的观察或数据。
- **解释**：对事实的因果推断或理论。
- **价值观**：我认为什么重要；它不必伪装成客观定律。
- **行为建议**：基于事实、解释和价值观，下一步怎么做。

### 2. 每条观点都有状态

```text
素材 Material
    ↓ 有清楚命题与来源
候选假设 Hypothesis
    ↓ 经验证或与较强证据相符
实用规则 Tested Rule
    ↓ 多情境适用、边界清楚、经反例检验
核心原则 Core Principle
```

这是管理状态，不是自动按使用次数升级的科学证明。遇到反例可**降级、修改、拆分或归档**；不得因为某观点是自己喜欢的，就跳过验证。

### 3. 每次新增，都要检查四种关系

- **支持**：给已有观点增加独立证据。
- **补充**：带来新边界、新机制或新场景。
- **冲突**：结论不同，先核对定义、证据质量与适用条件。
- **重复**：没有新增信息时只补来源，不重复造原则。

### 4. 发布前做一道隔离

个人原始经历、聊天记录、他人身份、健康和财务细节**默认私有**。公开文章是经过本人审核、去标识化并保留必要来源的衍生内容，不是将私人案例目录整体发布。

## 五、实验反馈：把认知变成可检验的行动

遇到具体问题，调用独立模块 **《个人快速判断与退出模型》**，而不是在知识库里无限延伸讨论。

```text
目标与现状 → 硬约束 → 选项与代价 → 可逆性
              ↓
      信息价值 / 低成本试验
              ↓
          决策与行动
              ↓
          退出合约
              ↓
    检查：继续 / 调整 / 退出
              ↓
     案例复盘 → 认知更新
```

**成果不只是“想通了”**：更好的成果是形成一个可执行决定，并记录什么证据会改变它。

## 六、一个跨领域例子

选择健身场所，表面归属 **健康**，实际还关联 **金钱、时间**。它调用的母题可能是 MQ-001（资源投入）、MQ-003（可逆性）、MQ-008（现状成本）、MQ-010（小实验）。

这类问题不一定要单独创造“健身房理论”。更好的方式是：保存案例，链接到共同母题，让同一个模型在未来职业选择或项目投入中复用。

## 七、持续修订与成功标准

| 阶段 | 要实现什么 | 完成标志 |
|---|---|---|
| V0.1 | 架构、母题、两篇核心说明、模板 | 能新增一条观点且有来源与状态 |
| V0.2 | 爱情模块试点 | 至少一个主题形成“来源→假设→案例→复盘”闭环 |
| V0.3 | 真实案例试运行 | 决策记录能在检查点回看并修正 |
| V0.4 | 网站化 | 两篇核心文档与分类入口可公开访问 |
| V1.0 | 跨领域知识网络 | 同一母题能连接不同领域的真实案例 |

**评价方式**：不是知识条数，而是能否更清楚地区分事实与解释、减少重复犯错、明确下一步行动、发现旧模型的失效边界。

---

**项目原则**：允许修订，保留版本；尊重证据，承认未知；记录失败，而不是抹掉失败。母题项目随新的来源、案例与验证持续更新。
