一、训练目标与训练体系

1. 当前训练目标

我目前主要以增肌训练为主，同时希望逐步提升整体力量表现。

长期来看，我希望将力量训练与肌肉发展结合起来，而不是只关注单一指标。

2. 我的训练分化

我目前以四个基础训练主题轮换：

  1. 胸部＋三角肌中束＋肱二头肌
  2. 硬拉＋背部＋三角肌后束＋肱三头肌
  3. 股四头肌＋髋内收肌
  4. 股二头肌（腘绳肌）＋后侧链

通常采用相对灵活的「练二休一」节奏。

一个常见安排是：

胸部日 → 背部日 → 休息 → 股四日 → 股二日 → 休息

如果连续完成胸部日和背部日之后，我感觉整体疲劳程度不高，有时会将原本的休息日替换成肩部训练日。

这时训练主题就从四个变成五个，但并不意味着每个周期都必须增加肩部日。

我不会严格按照固定日历训练。如果感觉身体状态不好，就会调整训练日或选择休息。

2. 杠铃平板卧推训练方法

我通常安排4–5个正式组，热身组另外计算。

正式训练主要采用自己目前的RPT式递减重量方法。

  • 正式组次数范围：约5–12次。
  • 主观努力程度：通常RPE 8–9。
  • 递减方式：后续组通常根据第一组的重量，每次减少相当于第一组重量约10%的负重。

例如以100kg作为示意起点，后续可能依次调整为90kg、80kg、70kg等。

这只是说明重量递减逻辑，不代表我每次都使用这些具体重量。

3. 其他动作的训练量

除了杠铃平板卧推之外，其他动作目前通常采用每个动作3个正式组、每组10–12次的安排。

具体训练表现与负重仍需要结合训练记录逐步补充。

4. 渐进超负荷的个人方法

我目前会通过增加重复次数或提高负重来推进训练。

如果某个工作组达到了自己设定的次数目标，且训练状态允许，我会考虑在后续训练中增加重量。

如果没有达到目标，通常会先保持重量，争取在下一次训练中增加完成次数。

这里的次数目标是跨不同训练场次逐步推进的，并不是简单地将5次、8次、10次、12次固定分配给同一次训练的不同组。

2. 传统杠铃硬拉

目前主要采用传统杠铃硬拉，架子硬拉作为备选动作。

热身阶段

正式训练前通常安排2–3组热身。

正式训练阶段

共5个正式组：

  • 前3组：相同的大重量，每组4–6次。
  • 后2组：采用RPT式负重递减，每组目标8–12次。

重量递减方法

我通常每组降低约10kg。

例如前三组使用120kg时，后续两组可能使用110kg和100kg。

状态较差时，我可能增大递减幅度，例如120kg→100kg→80kg。

未来可能尝试每组递减15kg，但目前并没有将其作为固定方式。

组间休息

  • 大重量组：约2–2.5分钟。
  • 递减重量组：约1分30秒。

整个传统杠铃硬拉训练环节，我一般安排20–25分钟。

3. 背部下拉与划船

我目前的背部训练通常采用两个下拉动作，并根据训练周期选择划船动作。

当前主要使用对握高位下拉、单手反握下拉、单手悍马机划船和T杠划船。

此外，当前训练中还会在T杠划船之后安排坐姿绳索V把划船。

不过，这些动作并不是永久固定的组合。我过去还使用过其他下拉和划船动作，会根据不同训练周期调整选择。

关于坐姿绳索V把划船的个人观察

我目前在这个动作中安排3个正式组，每组12次。

最近，我开始考虑删除或替换它。

原因是我感觉传统杠铃硬拉已经给下背部带来较多负荷，而完成前面的划船动作后，再进行V把划船时，主观感受到的额外收益已经不明显。

目前这只是我的个人判断，尚不能据此证明它属于无效训练量。

4. 三角肌后束

常规背部训练日通常选择蝴蝶机反向飞鸟：

3个正式组，每组目标8–12次。

具体完成次数根据当天状态调整。

5. 肱三头肌

肱三头肌部分通常只选择一个动作。

目前主要采用器械肱三头肌伸展，3个正式组，每组8–12次。

其他备选动作包括：

  • 直杆绳索下压
  • 绳索过顶臂屈伸
  • 上斜哑铃肱三头肌伸展

这些备选动作并不是每次全部完成。

2. 杠铃深蹲

热身阶段

正式训练前通常完成3个热身组，重量逐组递增。

正式训练阶段

通常安排4–5个正式组。

  • 前2–3组采用相同的大重量，每组4–6次。
  • 后续正式组通常降低约10kg，并争取完成8–12次。

组间休息

  • 大重量组：2–2.5分钟。
  • 递减重量组：约1分30秒。

这种方式属于我目前个人采用的RPT式训练安排，并不完全等同于标准反向金字塔训练。

3. 其他动作

哈克机深蹲、坐姿腿屈伸、单腿水平倒蹬和坐姿髋内收机，组间休息一般统一在1分30秒左右。

哑铃保加利亚蹲的组间休息时间暂未单独确认。

这六个动作通常在同一天按照上述顺序全部完成。

2. 热身安排

杠铃罗马尼亚硬拉之前通常先进行2个热身组。

目前尚未确认六角杠硬拉或其他动作是否分别进行额外热身。

3. 重量安排

这六个动作都采用各自动作正式组重量保持一致的方式。

也就是说，杠铃罗马尼亚硬拉的4个正式组使用相同重量；其他五个动作各自的3个正式组也保持相同重量。

不同动作之间不要求使用相同的公斤数。

4. 组间休息

六个动作的正式组间休息时间通常统一为90–100秒。

5. 当前训练量

按照目前记录，这个训练日包含19个正式组，另有杠铃罗马尼亚硬拉之前的2个热身组。

我目前会在同一次训练中完成杠铃罗马尼亚硬拉、六角杠硬拉和哑铃罗马尼亚硬拉。

后续需要结合实际训练体验，继续评估这些动作之间是否存在不必要的疲劳累积或训练量重叠。

六、可选肩部训练日

1. 增加条件

如果完成胸部日和背部日之后，我感觉整体疲劳程度不高，有时会用肩部训练替代原本的休息日。

这个训练日不是每个周期都必须执行。

2. 当前动作及顺序

顺序训练动作正式组数目标次数
1史密斯机推举4组8–12次
2站姿杠铃推举3组8–12次
3坐姿锤式握法器械肩推3组8–12次
4器械把手侧平举3组8–12次
5Y字绳索侧平举3组8–12次
6绳索反向后束飞鸟3组8–12次

这六个动作通常在同一次肩部训练中全部完成，共19个正式组。

3. 训练重量

目前，前五个动作各自的正式组通常保持相同重量。

绳索反向后束飞鸟的正式组重量变化方式尚未单独确认。

4. 组间休息

绳索反向后束飞鸟通常休息90秒，状态变化时可能调整为90–100秒。

其他五个动作已确认采用相同的组间休息时间，但尚未明确具体秒数。

5. 与常规背部日的区别

在常规背部日，我通常采用蝴蝶机反向飞鸟训练三角肌后束。

而在额外肩部日，我会安排肩推、侧平举及绳索反向后束飞鸟等六个动作。

因此，这属于完整的肩部训练主题，而不仅仅是一个后束专项动作。

七、训练恢复与休息安排

1. 基本训练节奏

我目前以「练二休一」为基本训练节奏，但不会强制按照固定日历执行。

有时连续训练两天之后，我仍然感觉状态不错；有时训练一天后，就会感到明显疲惫。

如果身体状态不好，我通常会选择休息。

2. 最大握力记录

我目前会使用握力器记录最大握力数值，并将当天结果与历史数据进行对比，观察是否存在明显波动。

这是我个人评估当天训练状态的一项辅助参考。

3. 主观疲劳观察

除了最大握力，我还会结合自己的主观疲劳感受决定是否训练。

我有时将这种疲劳体验称为“神经疲劳”，但目前没有通过专业检测证明其属于中枢神经系统疲劳。

因此，最大握力变化与主观疲劳感受只能作为个人观察信息，不能单独证明身体已经恢复或尚未恢复。

八、训练方法与观念

1. 渐进超负荷

我目前会通过增加完成次数或提高训练重量，推动训练表现逐步进步。

对于有目标次数区间的动作，我通常先尝试提高重复次数，再根据后续训练表现考虑增加重量。

2. RPT式训练

目前主要在以下动作中采用大重量与递减重量相结合的安排：

  • 杠铃平板卧推
  • 传统杠铃硬拉
  • 杠铃深蹲

但它们的具体安排不完全相同。

例如，传统杠铃硬拉和杠铃深蹲都是前几个大重量组保持相同重量，后续正式组再降低重量。

因此，这些属于我的个人RPT式训练方法，并非完全照搬某一套标准方案。

3. 训练量与恢复

我正在学习超量恢复、渐进超负荷和疲劳管理等概念。

目前，我还没有通过系统验证确定最适合自己的训练量和恢复周期。

在实际训练中，我会结合个人感受与训练表现，重新评估部分动作是否有必要长期保留。

例如，背部日的坐姿绳索V把划船，就是目前正在考虑调整的动作之一。
